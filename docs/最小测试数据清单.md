# 测试数据清单（预算约 500MB）

把项目根目录 `input/` 填到大约 500MB。主体仍是代码已经认识的四家：平安银行、招商银行、中国平安、华夏债券（含华夏债券C）。份量要够测同一家跨 2023–2025 年、同一年两家银行对比、基金问答、政策切块，以及建图谱要用的关系原句。

抽数只认这五个名字：平安银行、招商银行、中国平安、华夏债券、华夏债券C。指标只认营业收入、净利润、净值。股票代码不读。下面多出来的文件，是为了把这四家的年份、公告和基金法律文件补齐。

体积全部是估计，不是量过的 PDF。单份按这类文件常见体量取偏保守的区间，例如银行年报 15–40MB、中国平安年报 25–80MB、半年报 5–20MB、季报 1–8MB、基金招募说明书 2–15MB、公告 0.3–3MB。「建议计数」是为了把推荐集放在大约 400–500MB 的规划数。

## 文件怎么放

平放在项目根目录 `input/` 即可，子目录也会被递归扫到。入库只收 `.pdf`、`.md`、`.docx`、`.doc`。解析出来的 Markdown 和 `*_chunks.json` 在 `output/`，是程序写出的，不要拷回 `input/`。本清单不要放进 `input/`。

文件名必须含公司名或基金名。定期报告的文件名要含「报告」，用「年度报告 / 半年度报告 / 季度报告 / 中期报告」。公告用「公告」，业绩快报用「业绩快报」。

```
input/{代码}_{公司}_{年份}年度报告.pdf
input/{代码}_{公司}_{年份}半年度报告.pdf
input/{代码}_{公司}_{年份}第一季度报告.pdf
input/{代码}_{公司}_{年份}{类型}公告.pdf
input/华夏债券C_招募说明书.pdf
input/华夏债券_基金合同.pdf
input/基金FAQ.md
```

银行和中国平安的代码沿用 000001、600036、601318。基金代码以封面为准，可以不写进文件名。

去哪下：年报、半年报、季报和公告用巨潮资讯或公司官网；基金法律文件和定期报告用华夏基金官网或交易所公示；通知用中国人民银行、国家金融监督管理总局公开栏目；FAQ 用这些站点上的投资者教育材料整理。

## 研报和公司分析怎么测

问句用代码里的名字。官方 PDF 保持原文，数字以入库后实际抽到的为准。

- 同一年两家银行：问 2025 年平安银行和招商银行的营业收入、净利润；再问 2024 年。
- 同一家三年：问平安银行 2023、2024、2025 年净利润。当前代码不算同比，三年文件仍要备齐。招商银行、中国平安同样可以各问一遍。
- 缺口：拿掉一侧的 2025 年报再问比较。应说明缺该年该指标，不会用另一年的数填上。
- 冲突：若某家 2025 年有更正或补充公告，且同一指标出现两个数，应能看出冲突。没有更正公告就不要造一份。
- 华夏债券C 的赎回费用：答案应带持有期条件。
- 只问「平安」：应提示可能是平安银行或中国平安。
- 当天净值：问「今天华夏债券C的最新净值」。只有正文里有当天的 `YYYY-MM-DD` 才能答。公告日期不是当天，就应说明不能把历史净值当成今天的净值。不要编造一条当天净值。

当前只认这种句子：`平安银行2025年营业收入123.45亿元`（名字仅限平安银行、招商银行、中国平安、华夏债券C、华夏债券；指标仅限营业收入、净利润、净值；单位仅限亿元、万元、元、%）。年报里常见的「本行实现营业收入」抽不出数。财报要被标成 `financial_report` 且解析成带 `|` 的 Markdown 表，数字才会进入研报；表变成纯文字时整篇是 `parse_quality=degraded`，数字不会进入研报。这是抽取限制。官方 PDF 仍按原文下载，不要改写成上面这种句子。
